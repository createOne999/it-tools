# AGENTS.md

## Setup
- Use the pinned `pnpm@11.10.0` from `packageManager`; `pnpm-lock.yaml` and `pnpm-workspace.yaml` are authoritative, not `package-lock.json`.
- Install with `pnpm install --ignore-scripts`; pnpm 11 build-script decisions and dependency overrides live in `pnpm-workspace.yaml`.
- Prefer WSL/Linux shell on Windows: `build`, `test:unit`, `test:e2e`, and `test:e2e:dev` use `TZ=UTC` and source `./set_node_mem.sh`.
- Local Node is `.nvmrc` `22.19.0`; Docker builds with Node 24. Native deps may require `python3 make g++`.

## Commands
- Dev server: `pnpm dev`.
- Production build: `pnpm build` runs `vue-tsc --noEmit`, then sets `NODE_OPTIONS` from system RAM, then `vite build`; README warns this can need about 16 GB RAM.
- Typecheck/lint/format: `pnpm typecheck`, `pnpm lint`, `pnpm lint:fix`, `pnpm fmt:check`, `pnpm fmt`.
- PR/precommit verification from the PR template: `pnpm install --ignore-scripts && pnpm lint:fix && pnpm typecheck`.
- Unit tests are Vitest/jsdom/UTC: `pnpm test:unit --run`; focus one file with `pnpm test:unit --run src/utils/base64.test.ts`.
- E2E tests are Playwright under `src/**/*.e2e.spec.ts`: run `pnpm build` first, then `pnpm test:e2e`; focus with `pnpm test:e2e --project=chromium src/tools/<tool>/<tool>.e2e.spec.ts`.
- Against an already-running Vite dev server on port 5173: `pnpm test:e2e:dev --project=chromium src/tools/<tool>/<tool>.e2e.spec.ts`.

## App Wiring
- Main entrypoints: `src/main.ts` installs plugins and fetches `tools-settings.json`; `src/router.ts` builds routes; `src/tools/index.ts` assembles the tool list.
- Tools auto-register through `import.meta.glob('./*/index.ts')`; add `src/tools/<slug>/index.ts` exporting `tool = defineTool(...)`, do not edit routes manually.
- Runtime customization files are fetched relative to `BASE_URL`: `tools-filter.json`, `external-tools.json`, and `tools-settings.json`.
- For tool defaults/state, prefer `useQueryParam`, `useQueryParamOrStorage`, or `useITStorage`; settings keys are `<tool>:<param>` or globals like `default_locale`.
- Tool names/descriptions normally use i18n keys `tools.<slug>.title` and `tools.<slug>.description`; add at least `locales/en.yml`. Optional per-tool locale files under `src/tools/<slug>/locales/` are included by Vite.

## Codegen
- New tool boilerplate: `pnpm run script:create:tool <slug> [Category]`; it creates Vue, service, unit-test, and e2e skeletons, but metadata/i18n/tests still need real content.
- UI component boilerplate: `pnpm run script:create:ui <name>` writes `src/ui/<name>/<name>.vue` and `.demo.vue`.
- `auto-imports.d.ts` and `components.d.ts` are generated by Vite plugins; do not hand-maintain them as source API.
- Vue/Vue Router/VueUse/i18n helpers and components under `src/` are auto-imported, so existing files often omit imports for `ref`, `computed`, `useI18n`, and `C*` components.

## Lint And Build Gotchas
- Formatting is `oxfmt` only: 2 spaces, single quotes, semicolons, trailing commas, 120 columns, LF.
- `oxlint` forbids importing `useClipboard` from `@vueuse/core`; use local `useCopy` from `src/composable/copy.ts`.
- Browser builds intentionally alias/stub server or native deps in `vite.config.ts` and `pnpm-workspace.yaml` (`fs`, `isolated-vm`, `onnxruntime-node`, `unpdf/pdfjs`); keep these when changing bundling or deps.
- The `@` alias points to `src`.

## E2E And Deployment
- Playwright uses `data-test-id`, `locale: en-GB`, `timezoneId: Europe/Paris`, and serves built `dist` with `npm run preview` on `http://localhost:5050` unless `NO_WEB_SERVER=true`.
- `BASE_URL` affects Vite base, router history, PWA paths, and fetched runtime JSON; subfolder builds use `BASE_URL="/it-tools/" pnpm build` or Docker `--build-arg BASE_URL=...`.
- Docker uses `nginxinc/nginx-unprivileged`, listens on `PORT` default `8080`, and maps as `8080:8080`.
- Docker builds can restrict bundled locales with `--build-arg VITE_AVAILABLE_LOCALES=fr,en`; default UI language can be set at build time with `VITE_LANGUAGE` or at runtime with `tools-settings.json` `default_locale`.

## PR Workflow
- The PR template targets `chore/all-my-stuffs`, asks for a plain-English description, and expects the precommit verification command above.
